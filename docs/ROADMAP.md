# Roadmap

## M1 - Reproducible evidence framework

Publish sanitized causal-evidence schemas, machine-readable checks, reproducibility instructions and the +300s rejection / +600s validation note.

## M2 - Realized execution calibration

Compare quote/simulation with realized fills under a frozen, bounded multi-cycle protocol. Publish anonymized reconciliation methodology and explicit stop conditions.

## M3 - Hedge and capacity toolkit

Implement dynamic SOL hedge accounting with funding, trading fees, slippage and capacity constraints. Run a no-live-capital ladder across increasing notional sizes using real pool and market states.

## M4 - Historical replay and public release

Acquire the minimum necessary Meteora/Solana and hedge-market history, run a post-freeze multi-regime replay, and publish the exactness report, code, sample outputs and limitations.
